# 🚀 KspUtils

Небольшая консольная утилита для игры **Kerbal Space Program**.

Проект содержит набор вспомогательных инструментов для:

* расчёта **Delta‑V**;
* генерации названий ракет;

## 📦 Стек

* Java 26
* Maven

## ▶️ Запуск

```bash
mvn clean install
```

После сборки проект можно запускать через основной entry-point:

```java
ru.stavarachi.Main
```

## 📁 Структура проекта

```text
src/main/java/ru/stavarachi
├── app
├── config
├── handler
├── model
└── service
```

## ✨ Возможности

* Расчёт Delta‑V
* Генерация случайных названий
* Работа с физическими параметрами
* Сервисная архитектура
* Простая расширяемость
